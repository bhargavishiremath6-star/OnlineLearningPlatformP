# Online Learning Platform

A full-stack Java-based online learning platform developed as a mini project.

## Project Description

The Online Learning Platform allows users to browse courses, view course details, enroll in courses, complete lessons, and track their learning progress.

## Features

- Home page with featured courses
- Course listing and course details
- Course enrollment
- My Courses dashboard
- Lesson completion
- Progress tracking
- Course completion certificate
- Course search
- Responsive web design
- Java Spring Boot backend
- LocalStorage for basic progress persistence

## Courses

- Java Programming
- HTML & CSS
- C Programming
- Python Programming
- Web Development
